废土装备局 0.4.1 — Windows x64 朋友试玩版
================================================
这是本机浏览器试玩包，不是 APK、TapTap 原生安装包或正式发布版。
要求：64位 Windows 10/11；已安装且支持 WebGL 的 Edge 或 Chrome。
已自带 Node.js 运行程序，无需安装 Node.js、Cocos、npm 或其他依赖。

怎么开始
1. 把 ZIP 整个解压到一个文件夹。不要在压缩包里面直接双击。
2. 双击“开始试玩.cmd”（或 Start.cmd）。
3. 等待文件完整性检查，浏览器会打开 http://127.0.0.1:4187。
   没有自动打开时，复制这个地址到 Edge/Chrome。
4. 保留启动窗口。玩完按 Ctrl+C；浏览器标签页可以关掉。
不能只转发启动文件，需要发送整个 ZIP；不要删除、修改包内文件。
安全软件可能询问未签名脚本；请确认文件来自可信朋友。不要关闭杀毒软件。
程序不需要管理员权限，不对局域网开放。不需要放行公网或私有网络防火墙。

怎么玩
- 选择起手武器、领取工单；首次教程可跳过，菜单“资料手册”可重看规则。
- 把备存装备拖入5×6格子，或先点装备再点空格。
- R旋转预览，落下确认；Z撤销；Esc取消选择、关闭手册或确认窗。
- 电池和武器正交贴边（斜角不算）；护板贴边加伤。点卡片查看实际加成。
- 至少放入一把武器才能开战。每波限45秒，打完选补给并重新整理，共5波。
- 暂停、展开战报或规则会停止模拟，关闭后继续。
- 默认自由试玩开放17件装备、4把起手武器；研究路线使用基础12件和已研究蓝图。
- 结算金币可在菜单“装备解锁”解锁5件新装备；没有永久属性升级、商城或音乐音效。

存档与故障
- 存档在同一浏览器的本机站点数据里，不保存在此文件夹，不上传服务器。
- 请一直使用同一浏览器、普通窗口和 http://127.0.0.1:4187。
  隐身模式、换浏览器、换地址/端口或清除站点数据会导致无法读取原存档。
- 刷新恢复最近已提交状态；战斗恢复后保持暂停，不补算离线时间。
- 同时只开一个游玩标签页。不同版本同时运行可能发生存档冲突。
- 如端口被其他程序占用，会提示失败；本程序不杀进程、不自动换端口。
- 若文件校验失败，请从原 ZIP 重新完整解压；不要强行跳过校验。
- 报错时给发送者发启动窗口文字/截图，并说明 Windows、浏览器版本和操作步骤。
- 本包启动程序仅提供本机静态文件，无账号、广告、遥测或游戏联网请求；
  浏览器自身的更新/扩展/联网行为不属于游戏。未测试真实手机及其他电脑兼容性。

默认保留全开放自由试玩；切到研究路线后，只有基础12件和已研究蓝图进入新工单掉落池。研究不直接赠送局内装备，不增加永久属性。
现有工单继续原规则；研究和模式切换只在结算领取后的菜单可用。存档仍属于原浏览器同一站点。

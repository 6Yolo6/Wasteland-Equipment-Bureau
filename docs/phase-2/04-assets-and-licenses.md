## 开发工具与引擎

- Cocos Creator 3.8.8 沿用已安装工具链。引擎文件自带上游版权/许可通知；编辑器软件与开源引擎许可不可混为一谈。
- TypeScript 4.9.5 仅用于检查/测试，采用安装包自带 Apache-2.0 许可材料；未复制编译器到游戏 assets。
- Node.js、Chrome、Playwright 是本机开发/测试工具，不是新增游戏运行时依赖；分发条款以各自上游材料为准，后续工具打包时再核查。
- 本阶段未新增 npm 依赖、未下载字体/贴图/音乐/第三方图标库。
- 最终 TapTap 包的引擎/插件/广告 SDK 通知与数据处理清单仍需实际接入后核查；本台账不代替发布审计。

本项目自己的公开源代码许可尚未由用户决定。本阶段不会擅自以 MIT、Apache 等许可证发布用户工程或推送远端。

# 玩法设计评审：15件装备、错峰检修与一次性急救

> 后续状态：本评审针对0.2.2／15件配置的静态判断保留为历史；2026-10-20用户追加要求后，0.2.3新增I16破甲与I17泡沫，普通池从10增至12、开发池从15增至17。新增内容和实测见 [交付记录](<D:/taptap/Wasteland Equipment Bureau/docs/phase-2/06-manual-and-supplies.md>)，下文未重新宣称平衡结论。

日期：2026-10-20。依据：catalog.ts、loadout.ts、combat.ts、run.ts、FieldManual.ts及2026-10-15试玩反馈。当前配置为 **mvp-0.2.2**；旧反馈的“开发池14件、补给每波重置”不能覆盖新增封装急救包。本评审仅静态阅读，未运行构建、浏览器或平衡实测；以下风险为机制推论，指标均待人工验证。

## 1. 已实现边界与现有玩法风险

- **出勤已实现**：5×6背包、五波自动战斗、每波45秒清场；首波按装配满血，其后继承生命，护盾重算。补给三选一，每组两件一起入备存；战斗中不能换装或手动用药。
- **掉落已实现**：15件配置不等于标准池全开放。标准池10件；I04喷嘴、I10盐水、I12铜线、I14侦测、I15封救仅在当前全开放开发配置中可掉落，尚非永久解锁系统。

| 装备覆盖 | 已实现的取舍 | 风险／待验证判断 |
|---|---|---|
| I01钉线、I02折板、I03短刃、I04喷嘴 | 钉线与短刃2格，折板与喷嘴3格；折板带溅射，喷嘴最多打3个目标。固定加伤逐命中生效，护甲也逐命中扣除；短刃可组惯性齿组。 | 快武器更吃固定加伤，多目标武器在单首领波失去额外目标收益。若这些差异不改变选装，四武器可能退化为只比输出；不能用面板伤害直接判强弱。 |
| I05护板、I06披片、I07电池、I13角铁 | 护板4格兼盾、减伤及邻接加伤；披片3格加最大生命但装卸不回血；电池1格供电，同类不叠加；角铁3格加伤，同武器最多+3。 | 护板可能成为通用答案，电池填缝可能掩盖大模块的机会成本。披片晚装不补当前生命，但会改变40%急救阈值，易被误判为无效。 |
| I08回收、I12铜线、I14侦测 | 回收靠击杀补盾，每波实际回收合计最多20；铜线2格，加开场盾并可组回路；侦测4格，加5%暴击率。 | 单首领波回收盾到最后击杀才产生，随后波次结束且盾不继承，不能提供该波生存价值。侦测随机收益难感知；铜线可能只因加速入选。 |
| I09急救、I10盐水、I11除锈、I15封救 | 急救2格，每波一次18；盐水2格，每8秒回5、每波4次，满血仍耗；除锈1格，前三次基础攻击忽略1甲，无甲也耗；封救1格，整次出勤一次26，用后波末移除，不参与洁净急救。 | 前四波首个敌人都无甲，除锈可能在装甲敌人前耗尽；盐水可能满血耗次或来不及触发。封救小且单次量大，急救却可跨波复用，不能把26与18比较成直接升级。 |

**三件套已实现**：洁净急救必须由急救匣同时贴盐水与除锈，占用至少5格，给急救匣单次回复+6；独立补给若浪费，成套不等于净赚。惯性齿组占用至少7格，短刃每第3次基础攻击追加5，但仍扣护甲，原目标已被基础攻击击杀时不转移追加；应与同格数散装比较，而非仅追求亮起组合。

**错峰检修已实现**：同一铜线正交接电池及两件武器实例，只启用1组；超过两把按获得顺序选前两把。两把各完成一次基础攻击，最早将出手的存活敌人下一击延后0.3秒，每波最多3次；同一快武器连发不替代慢武器。获选武器另有10%冷却缩短，与直接贴电池合计上限20%。武器先于同tick敌人行动，存在延后后抢杀的窗口；但延后不必然少挨一击，3次脉冲不等于固定免伤。

**急救顺序已实现**：受到生命伤害、仍存活且生命≤最大生命40%才检查，不会低血开战即用或复活。多个急救按获得顺序逐个检查，先回复可能让后面的封救保留，也可能在深度低血时同击消耗多个。封救用后本波仍占格，下一整备才腾格；未触发可留到下波，放备存可主动保留。

## 2. 优化建议（按优先级；本次均未实现）

### 1）先验证封救的跨波取舍能否被理解

保留寿命与治疗量，先让玩家说出“现在装备还是留备存”的理由。若误解集中，再建议补急救共装的获得顺序示例，不引入手动施药。

**假设／指标**：只看手册后预测低血开局、仅盾受击、致死、存活低血、共装急救五种情况；记录预测正确数、封救触发波次、实际回复、未用结束次数与备存理由。若普遍认为每波补回或可以复活，先改说明而非数值。

### 2）证明检修不只是加速配件

用同工单比较合法与断开回路，分别解释冷却变化和延后事件；暂不改限额与获得顺序。若玩家只感知加速，建议强化“两武器各已开火／剩余脉冲”的因果呈现，再讨论时序参数。

**假设／指标**：比较快＋快、快＋慢的自然可得布局，记录首脉冲时刻、脉冲数、延后对象、来袭次数、承伤与清场时间；让玩家预测并复盘一次脉冲。合法／断开也改变加速，不能把全部承伤差归因于延后；开火次数还改变暴击随机数消耗，须记录暴击，不把单局差值当平衡结论。

### 3）验证格子与共边确实存在机会成本

先观察护板＋电池是否成为默认解，不直接削弱。用现有装备比较多放武器、加护板／角铁、为铜线留共边；若背包宽裕、增配件几乎无代价，先验证布局压力，不继续加道具。

**假设／指标**：同工单、同补给、同装备集合，只换合法布局；记录占格、有效供电武器数、舍弃邻接、备存选择、清场时间和剩余生命。观察是否主动断组合换输出／防御；若各布局同样够用且无人弃装，格子策略尚未得到验证。

### 4）验证支援的波次价值，不盲目抬数值

在已有整备阶段观察换装：末波回收器可腾位，除锈考虑无甲目标先耗药，盐水考虑受伤与战斗时长，披片不能当即时治疗。若长期无有效收益，再讨论现有触发规则，不直接加治疗、穿甲或暴击。

**假设／指标**：记录盐水实际／0回复，除锈对有甲目标的有效次数，回收实际补盾及随后吸收，披片装卸前后生命与阈值，侦测暴击次数／实际伤害。假设阶段性换装有意义；会解释却仍始终不选某件时，才列入后续数值或规则候选。

### 5）分开检验标准池与开发池

开发池评估检修、洁净急救和封救；标准池单独评估能否自然形成不同打法。不要把全开放试玩的机制可达性写成标准流程已具备，不在本评审追加解锁或道具实现。

**假设／指标**：两池分别记录初始武器、补给选项与选择理由、铜线／封救是否出现、首次成套波次、失败原因。假设路线差异不只由稀有掉落决定；整局未出现某机制，记“未接触”，不计为不理解或无效。

## 3. 人工复测口径

以上是**待验证假设，不是实测结果或验收通过声明**。记录池／版本、种子、初始武器、逐波补给、布局与获得顺序；同工单配对只报告观察差异。覆盖多人波、装甲波、单首领波，以及封救未触发留存、触发后下一整备消失两条路径。机制未自然掉落时换工单或记未接触，不靠赠装改血验证正常流程。优先收集“为什么这么摆、为什么现在用”的解释，不以组合数、能通关或单次暴击替代策略深度证据。本评审不承担构建、浏览器手册交付或真机核验。

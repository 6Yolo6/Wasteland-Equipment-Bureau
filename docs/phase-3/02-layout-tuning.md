## 2. 实验口径

- 两池（普通锁定／开发全开放），同种子、同起手；两种策略均领取每波**第一个真实补给选项**，没有挑战斗结果或赠装。
- 首个空位策略：按获得顺序、旋转0/90/180/270、逐行寻找合法空位，不交换、不整理。
- 局部布局策略：先按上述策略装备同一批物品，再进行至多两轮合法移位；只用装备参数启发式评分，不读取模拟胜负做搜索，不声称最优。
- **逐波严格配对**：沿首个空位路线取输入，同一拥有物品、同一已装备实例、同一备存、同一获得顺序、同一初始生命与初始RNG，仅位置不同。程序逐对断言装备集合一致。
- 全流程两条路线可因存活、耗材移除／留存、后续空间而分化；因此不把整局胜场差都归因于纯布局。初始RNG相同也不意味着攻击时序改变后暴击抽样一致。
- 评分使用实际平均冷却而非首击向上取整；多目标、溅射、三击追加及治疗评分仍是粗略启发式，不考虑每波实际目标数／护甲／治疗浪费／检修窗口，可能做出更差选择。
- 已否决单纯加强后两波压力的候选：小样本中通关下降明显，但布局优势不稳定，喷嘴更受损。没有把这些候选写进正式敌人表。
